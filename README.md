# Tucson Fix & Flip Loan

Astro SSR site for Tucson-area fix-and-flip funding inquiries. Program terms are fetched server-side from the GA/AZ lender terms sheet; `src/data/loanTerms.ts` contains last-known fallback terms and the worked-example calculations. The site is an introduction service, not a direct lender.

Phone: no published call number. GA4: not installed until a site-specific measurement ID is supplied. `src/layouts/Base.astro` is the location for a future GA4 script.
